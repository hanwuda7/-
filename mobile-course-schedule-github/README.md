# 手机端课程表

这是一个可直接在手机浏览器使用的 2026-2027 学年第一学期课程表，包含：

- 自动计算当前周、当前日期和当前星期
- 上一周、下一周、回到本周
- 左右滑动切换周次
- 当日分节课程时间线
- 当前课程高亮和下一节课倒计时
- 点击课程查看教师、教室、节次、周数和数据来源
- 单双周、特定周次和课程冲突检测逻辑
- PWA 支持，可通过浏览器“添加到主屏幕”

## 1. 在电脑上打开

推荐在项目目录打开 PowerShell，执行：

```powershell
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

也可以直接双击 `index.html`。直接打开时会使用 `data/courses.data.js` 离线副本；PWA 安装和缓存功能需要在本地服务器或网站上才可用。

## 2. 放到网上

这是一个纯静态项目，整个 `mobile-course-schedule` 文件夹可以上传到：

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel
- 任意支持静态文件的网站空间

部署时把 `index.html` 所在的文件夹作为网站根目录。例如 GitHub Pages 上传后，访问类似：

```text
https://你的用户名.github.io/仓库名/
```

## 3. 在手机上打开

### 同一个 Wi-Fi 局域网

1. 在电脑上运行 `python -m http.server 8080`。
2. 在电脑执行 `ipconfig`，找到类似 `192.168.1.23` 的 IPv4 地址。
3. 手机与电脑连接同一 Wi-Fi。
4. 手机浏览器访问 `http://192.168.1.23:8080`。

如果 Windows 防火墙弹窗，请允许 Python 访问专用网络。

### 已部署网站

直接在手机浏览器打开部署后的 HTTPS 网址。

## 4. 添加到手机主屏幕

### iPhone / Safari

1. 打开网页。
2. 点击底部的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 确认名称后点击“添加”。

### Android / Chrome 或 Edge

1. 打开网页。
2. 点击右上角菜单。
3. 选择“安装应用”或“添加到主屏幕”。
4. 按提示确认。

## 5. 以后如何修改课程

课程数据独立保存在 `courses.json`。需要修改或新增课程时：

1. 用文本编辑器打开 `courses.json`。
2. 按照现有记录修改 `name`、`teacher`、`location`、`weekday`、`periods`、`weeks` 等字段。
3. 执行下面命令，生成直接双击打开时使用的离线副本：

```powershell
node tools/sync-data.mjs
```

4. 刷新网页。

字段说明：

- `weekday`：`1` 表示星期一，`7` 表示星期日。
- `periods`：节次数组，例如 `[3, 4]`。
- `weeks`：生效周次数组，例如 `[3, 4, 5, 7]`。
- `rawWeeks`：保留截图中显示的原始周次文字。
- `color`：课程卡片左侧色条颜色。

单双周可以在 `weeks` 中只填写对应周次，例如单周 `[1,3,5,7]`，双周 `[2,4,6,8]`。特定周直接写具体数字即可。
